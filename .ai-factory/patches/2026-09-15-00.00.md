# Workflow launcher used the wrong Python environment

**Date:** 2026-09-15
**Files:** `run_all.sh`, `README.md`
**Severity:** medium

## Problem

The exporter failed with `TypeError: __init__() got an unexpected keyword argument 'prompt_mfa'`.

## Root Cause

The launcher selected system `python3` with garminconnect 0.2.8, while the project
virtual environment contained the required 0.3.11 version. The older API lacks
the MFA constructor argument and uses a different authentication backend.

## Solution

Run from the script directory and prefer `.venv/bin/python` for all pipeline
steps, retaining the shell Python fallback. Log the interpreter selection and
document installation into the project environment.

## Prevention

Check dependency versions using the actual launcher interpreter. A temporary
launcher regression harness failed before the change and passed afterward,
confirming all three steps select the project environment without network calls.
Additional coverage could check the fallback interpreter and fail-fast behavior.
